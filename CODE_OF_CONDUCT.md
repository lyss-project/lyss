# Code of conduct

LYSS is a small open-source project. Everyone is welcome to use it, report problems, suggest ideas
and contribute, whatever their experience, background or the network they run.

## What we expect

- Be respectful and patient, in issues, pull requests, discussions and e-mails.
- Discuss ideas and code, not people. Disagreeing is fine; insulting is not.
- Help newcomers: everyone started with their first switch.
- Never post real secrets or another organisation's real configurations, addresses or names.
  Use fictitious examples (see [CONTRIBUTING.md](CONTRIBUTING.md)).

## What is not accepted

Harassment, insults, discriminatory jokes or language, personal attacks, threats, publishing someone
else's private information, and spam.

## What happens

The maintainer may edit, hide or delete comments, close issues or pull requests, and block accounts
that do not follow this code. This is done on a best-effort basis by a volunteer, without any
guaranteed response time.

To report a problem privately, write to lyaazale@lyss.dev, or use GitHub's "Report content" link.
Security vulnerabilities follow [SECURITY.md](SECURITY.md) instead.

This code applies to the LYSS spaces (repository, issues, discussions, lyss.dev contact) and to
people representing the project elsewhere.
