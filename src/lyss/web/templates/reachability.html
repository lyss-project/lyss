1. Probe from a PC of the network to test

On this machine, python -m lyss reachability targets --out switches.txt lists the switch addresses (no name, no credential). On the PC to test, with LYSS 0.15 or later (pip install --upgrade lyss):

lyss probe --targets-file switches.txt

It opens and closes TCP connections to the management ports ({% for p, s in ports.items() %}{{ p }} {{ s }}{% if not loop.last %}, {% endif %}{% endfor %}) and sends nothing else. Only probe networks and switches you are responsible for.
