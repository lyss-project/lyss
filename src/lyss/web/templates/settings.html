E-mail alerts

After each scan: new failures (regressions), collection errors and newly discovered switches.

SIEM events (syslog / Wazuh)

After each scan, one JSON event per switch (level, counts), per failed control, per regression or fix, and per collection error. Ready-made Wazuh rules: integrations/wazuh.

The events file is for a local agent (Wazuh <localfile> with <log_format>json</log_format>, Filebeat). Evidence lines are redacted: no password hashes, keys or communities.

Rescan on change (Wazuh)

When Wazuh reports that a switch configuration changed, or that an administrator session on it ended, LYSS rescans that switch at once. LYSS queries the Wazuh dashboard with a read-only account (integrations/wazuh/reader-account.sh); nothing connects to this machine. LYSS's own sessions are ignored.

CISO Assistant

Sends the fleet report as a new revision of an evidence in CISO Assistant (open-source GRC), for ISO 27001 audits.
