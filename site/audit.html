Audit a switch configuration in your browserAuditez une configuration de switch dans votre navigateur

Paste a saved configuration and get the LYSS assessment: every control, the evidence and the fix. LYSS runs inside this page. The configuration is never sent anywhere, and the page's security policy forbids it from contacting any server other than lyss.dev.Collez une configuration sauvegardée et obtenez l'évaluation LYSS : chaque contrôle, sa preuve et sa correction. LYSS s'exécute dans cette page. La configuration n'est envoyée nulle part, et la politique de sécurité de la page lui interdit de contacter un autre serveur que lyss.dev.

Cisco / HPE / Arista: show running-config. MikroTik: /export (RouterOS 6: /export hide-sensitive). SONiC: /etc/sonic/config_db.json. Zyxel GS1900: show version or the System Information page (firmware check). You can also drop a file here. Secrets are hidden in the results; you may remove passwords before pasting.Cisco / HPE / Arista : show running-config. MikroTik : /export (RouterOS 6 : /export hide-sensitive). SONiC : /etc/sonic/config_db.json. Zyxel GS1900 : show version ou la page System Information (contrôle du firmware). Vous pouvez aussi déposer un fichier ici. Les secrets sont masqués dans les résultats ; vous pouvez retirer les mots de passe avant de coller.
